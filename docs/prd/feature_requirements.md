# Feature Requirements

## 1. Membership & Access

### Referral-Only Entry

VVS Members is not open registration. Every new member must:

- Have an invite code from an existing member.
- Be approved (automated and/or manual) by the platform.

### Tiered Access

Members have tiers (Free, Verified, Pro) that control what they can do on the platform (e.g., how many invites they can generate, listings they can create, messaging limits, etc.). Tier progression is driven by completed and rated transactions.

### Onboarding Flow

New members should be guided through a short onboarding flow that:

1. Confirms their invite code and referrer
2. Helps them complete their profile (bio, profession, category, skills, photo)
3. Encourages identity verification (NIN/BVN/etc.)
4. Helps them decide whether they are primarily hiring, offering services, or both

> For more detail on the onboarding flow, see the UI inventory and the auth/registration UX spec.
